# Abmiti (Antigravity / agent runtimes)

Load the repository root **AGENTS.md** before editing. This project is a personal finance tracker with:

- `client/` — React SPA at `/abmiti/`
- `server/` — Express API, JWT, optional Google OAuth, SSLCommerz, Mongo or MySQL
- `mobile/` — Flutter WebView shell

Rules: dual-database repositories, bilingual i18n, no public admin registration, no secrets in git, do not reimplement the ledger in Flutter.
